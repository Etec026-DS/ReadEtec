# ReadEtec 📚

Sistema de biblioteca desenvolvido para a atividade **Construção de Software com IA** da Etec.

🌐 **Acesse online:** https://readetec.onrender.com

Login de administrador: usuário `admin`, senha `12345678` (projeto escolar: o login é apenas simbólico).

## Funcionalidades

- Cadastrar livros
- Cadastrar usuários
- Realizar empréstimos
- Registrar devoluções
- Consultar livros disponíveis
- Pesquisar por título ou autor

## Tecnologias

- HTML, CSS e JavaScript (sem frameworks)
- `localStorage` do navegador para guardar os dados
- Hospedagem: Render (Static Site)

## Como executar

- **Online:** https://readetec.onrender.com (publicado no Render; cada `git push` atualiza o site automaticamente)
- **No computador:** rode `python3 -m http.server 8000` na pasta do projeto e acesse http://localhost:8000
